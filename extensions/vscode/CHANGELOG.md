# Changelog

## 0.0.1

Initial release.

- Syntax highlighting for `.kal` single-file components (embedded TS/CSS/HTML,
  interpolation, directives, Kallo template tags, `$keyword` APIs).
- Language server: structural diagnostics, CSS validation, completion, hover, and
  document symbols.
- Snippets for pages, layouts, components, and common `$keyword` blocks.
